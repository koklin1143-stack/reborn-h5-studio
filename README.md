# 物之再生 · 共创工作室

2026-10-30 / v12。依据新包功能与最新观片器视频迭代的手机端 H5，可持续调整，不作为最终定案。

## 在线访问

- 原型：https://koklin1143-stack.github.io/reborn-h5-studio/
- 源码：https://github.com/koklin1143-stack/reborn-h5-studio

GitHub Pages 从 `main` 分支根目录发布。修改页面后执行 `npm run build` 并提交、推送；构建同时更新根目录 `index.html` 和单文件原型。线上作品仍保存在访问者当前浏览器中。

## 运行

无需安装依赖。推荐使用已安装的 Node.js，在本目录执行：

```powershell
npm start
```

打开终端显示的 `http://127.0.0.1:8765/`。首页默认搪瓷；一级导航只有共创、积分、我的。

也提供 `物之再生-H5-单文件.html`，可直接打开。正式演示建议使用 HTTP 地址：浏览器对 file:// 的 IndexedDB 支持和数据隔离策略不同；本轮实测的是 HTTP 方式。单文件与源码均无远程脚本、字体、图片或 API 请求。

手机端体验需把静态文件放在手机可访问的静态服务器上；默认启动脚本只监听电脑本机地址，不会自动对局域网或公网开放。桌面预览限制为手机宽度。

## 已实现

- 共创首页按当前品类展示独立系列；滑动、前后箭头、侧卡和方向键均不跨品类。类别按钮切换系列并恢复该系列上次所选物件。当前为 3 款搪瓷、2 款邮票、2 款糖纸、1 款工业零件；单件系列停用翻页。侧面使用 7 个循环展示槽位（中央 1 个隐藏，左右各 3 个），素材少时循环复用本系列已有图像；计数仍对应实际条目，不增加虚构作品。
- 队列末端卡片沿下方闭合弧线绕回另一侧；侧卡从近至远的透明度为 0.83 / 0.58 / 0.23，虚化为 0 / 0.7 / 2.12px。中央使用固定玻璃层与独立的前后两张照片：斜向抽离、下沉，再从侧下方抬入，途中有透视、轻微失焦与亮度变化。拖动时预览下一张，未达阈值则回弹；名称围绕横轴滚转。连续切换从当前呈现位置衔接，完成后清理旧层；支持减少动态效果。
- 四种主题外框改为 Three.js 程序建模：搪瓷连续弧面卷边与釉层、邮票细齿孔与三层薄纸、糖纸沿折线起伏的薄片、工业零件金属倒角与内凹压边。外框保持暗色，框内作品恢复彩色，侧卡保留灰阶。模型采用灯光和环境反射，不加载外部模型或贴图。静止时停止重绘，拖动只作小幅响应；WebGL 无法初始化时保留 CSS 外框与完整操作。
- 类别文字导航位于主动作上方；全部物件与问一问在首页顶部。积分和文化权益保持辅助层级。
- 四类自绘示意物件：搪瓷、邮票、糖纸、工业零件。搪瓷工作台可切换杯/盘；其他类别保留各自比例与形态。
- 全部物件抽屉、详情、收藏；本地关键词和同义词搜索，有示例、清空、无结果和返回路径。
- 编辑：拖动、水平/垂直位置、缩放、旋转、配色、纹样与个人图片替换、撤销/重做、重置、大图预览。
- 节流自动保存、刷新恢复；普通返回保存进度；明确结束提供保存退出、继续和二次确认放弃。
- 同类替换保留参数且可撤销；跨类别通过一次原子写入保存原草稿并新建独立草稿。
- 命名、保存作品、创作想法、结果页、继续编辑、作品/草稿/投稿/收藏分组和删除确认。
- 可选演示投稿，独立确认说明、不可变作品快照、状态反馈；编辑已投稿作品会建立新副本。
- 演示积分总览、规则和时间线；首次完成 +20、首次演示投稿 +5，规则在 `prototype/model.js` 集中配置。同一设计重复保存/投稿不会重复记分，删除记录也不重置已计分事件。
- 数据读取失败暂停写入；保存/投稿/换类别失败不误报成功，可重试，原作品保留。

## 数据与边界

IndexedDB 数据库 `reborn-studio`：`state` 保存版本 6 的记录、编辑历史和界面状态，`images` 分开保存图片 Blob。图像解码后最长边缩至 1400px；支持 PNG/JPG/WebP，限制 12MB。图片不会发送服务器。临时对象 URL 在重新打开时从 Blob 重建。

旧版 localStorage 键 `studio3.h5.iteration3` 首次迁移时只读，导入作品、草稿、投稿快照与收藏；旧数据不删除。不导入资料征集服务，也不为旧作品自动补发演示积分。数据属于当前浏览器及访问来源，换地址、换浏览器或清除网站数据可能无法看见原记录。此版本没有云同步与跨设备恢复。

投稿和积分均为本地演示，没有馆方账户、审核接口或真实文化权益。素材为本项目自绘示意，不是已核实馆藏图像；参考图仅用于风格。没有 AI 服务，搜索是本地匹配。数字设计尚未通过馆方授权、版权、工艺、量产审核。实体生产、正式投稿和积分账户需要后端及馆方确认。

## 源码与检查

页面保留原生 HTML/CSS/JavaScript。Three.js 0.186.1 已预打包到本地模块，打开源码或单文件无需联网、无需安装。只有修改 3D 模型源码时才需要开发依赖（Three.js 与 esbuild，均已锁定版本）。

- `prototype/model.js`：素材数据、草稿/作品/投稿业务、积分防重、撤销重做、搜索。
- `prototype/storage.js`：IndexedDB 队列、Blob、旧数据迁移。
- `prototype/art.js`、`objects.js`：复用原创纹样，器物 SVG 模板。
- `prototype/views.js`：各页面模板；`film-home.js`：观片器首页、侧卡景深与环绕动效；`film-optics.js`：双照片拖动、抽入与回弹；`reel.js`：循环展示队列与槽位复用；`app.js`：导航、交互、自动保存与错误恢复。
- `source/frame3d.js`：可维护的 Three.js 模型、光照与生命周期；`prototype/frame3d.js`：预打包运行模块；`frame3d.css`：模型与彩色卡片的叠层。
- `prototype/styles.css`：基础手机布局与安全区；`film.css`：基础暗色分类材质与中性灰阶视觉、弧形薄卡、观片器和减少动态效果。

```powershell
npm run lint
npm test
npm run build
```

如需修改 3D 模型：先执行 `npm ci`，再执行 `npm run build:frame` 与 `npm run build`。Three.js 的 MIT 许可证在 `licenses/three-MIT.txt`。

`lint` 是零依赖检查：Node 语法、本地资产引用和 CSS 括号检查，不等同于 ESLint。`test` 使用 Node 内置测试运行器；`build` 把模块与样式打入单文件，源码仍可维护。

本轮实际执行结果与浏览器检查见 `docs/本轮取舍与验证.html`。测试故障注入验证了业务原子性，不代表已模拟每一种真实磁盘或浏览器异常。尚未在真机 Safari / 微信 WebView 上验证，也未验证多窗口同时编辑冲突；演示建议单窗口使用。
