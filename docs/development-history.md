# 物之再生 · 手机 H5

**关机后重新使用**　双击「启动预览.cmd」，本机服务会在后台启动并打开[我的作品](http://127.0.0.1:8879/index.html#mine)。已经打开项目的浏览器可直接刷新原标签页。草稿和作品保存在创建它们的浏览器里。

**本机纹样生成**　从[共创首页](http://127.0.0.1:8879/index.html#discover)选「用图片、文字或手绘开始」。在「画几笔」里，先点「先看 AI 重塑的造型」。百炼识别题材，读出画中具体的姿态、比例与局部神态；H5 用 Perfect Freehand 记录新笔迹，支持压感笔与手指。素形生成使用两份参考，Magenta 简化的大姿态，以及从可见原画中选出的几段真实笔迹。单色稿先从主体本身提炼纹元，确认后按所选参考的主墨与点墨分版，透明处露出器身底釉。点「对照我的草图」可以在同一处查看原画。你可以改主体提示、换一个造型，或点「用这个造型制纹」，让百炼只参考选定的素形设色。识别和素形生成在第一次确认后调用，制纹在采用后另调用一次。草图、素形与完成的纹样分别保存。照片与文字仍通过设计说明生成一张纹样，项目原纹样使用自绘参考。

本机服务使用 `DASHSCOPE_API_KEY`、`BAILIAN_WORKSPACE_ID`。若 8879 已运行原预览，可在项目根目录运行 `powershell -File scripts/start-pattern.ps1` 启动 8882 端口的本机规则服务。浏览器优先同源，并检查规则版本。手绘画笔使用 [Perfect Freehand 1.2.3](https://github.com/steveruizok/perfect-freehand)，MIT 许可随单文件与[项目副本](licenses/perfect-freehand-MIT.txt)提供。姿态参考的组件见 [Magenta 来源记录](licenses/magenta-source.md)。取消会终止等待和尚未开始的后续步骤；已提交的调用按服务实际结算。一份已确认的纹样进入工作台时按全图原色开始。旧草稿可在「版本」里恢复确认稿，保留当前器物与釉色，可撤销。研究来源、图像权限边界与樱桃实测见 [转化规则](docs/enamel-pattern-rules.html)。

共创、作品广场、工作台、积分与我的作品共用黑白灰界面，展品与创作素材保留原色。后续调整排版或控件，请先查阅[手机界面设计规范](docs/mobile-design-system.html)。颜色、字号、边距和基础控件集中在 `prototype/design-system.css`。

从项目根目录运行 `npm start`，访问终端显示的地址。开发页位于 `/prototype/index.html#discover`，积分页位于 `/prototype/index.html#points`。运行 `npm run build` 会更新自包含 HTML。移动布局验收脚本 `scripts/qa-mobile-system.cjs` 支持通过 `QA_URL` 指定预览地址。

## 统一数据与持久化

`prototype/schema.d.ts` 定义 heritageObject、motif、vessel、draft、work、submission、pointEvent。`foundation.js` 给原有渲染字段提供兼容层，避免重写成熟流程。

例：来源为 `object:enamel-peony` 的搪瓷盘示意，纹样为 `motif:enamel-peony`，最终应用可以为 `vessel:enamel:cup`。换杯/盘不修改来源物件，换纹样也保留最初来源；当前都是项目自绘示意，非核实馆藏。

草稿保留 sourceObjectId/sourceMotifId、userImageAssetId、prompt、sketchAssetId、aiVariants、selectedVariantId、editParams、patternLayout、vesselId/vesselType、vesselPlacement、saveStatus 和 provenance。未接入字段为空，不伪造 AI 输出。兼容旧 itemId/canvas/imageId 与二维编辑参数。器型位置参数与纹样参数分离，当前画布仍为二维示意。

数据库仍为 `reborn-studio`，物理版本 1，沿用 `state` / `images` 两个 store；档案 schema 升为 8，读取时兼容 6/7。原作品、图片 ID、奖励身份与已发积分保留，不补发积分。未知版本停止写入。旧 localStorage 导入逻辑继续保留，原数据不删除。

- `LocalStore.commit(state, [{id, blob}])`：同一事务写档案和 Blob，失败一起回滚。
- `LocalStore.saveDraft(draft, assets)` / `getDraft(id)`：草稿最小接口。
- `LocalStore.getAsset(id)` / `imageURL(id)`：读取原 Blob、生成本机临时 URL；重启后从 Blob 重建，不把临时 URL 当永久地址。
- `storage-driver.js`：原生 IndexedDB 小封装；`storage.js`：迁移、排队、对象 URL 与领域校验。

## 服务接口与真实性

`Services.configure(kind, provider)` 注册 ai / images / models 适配器，provider 实现 `run(input, {signal})`；`Services.request` 返回统一 ok/code/data，未配置返回 NOT_CONFIGURED，错误或取消不冒充成功。接口不包含真实密钥或远程请求。

当前没有外部 AI、正式馆藏照片、器型 GLB、账号云同步、跨用户共享、正式公开、馆方审核/积分权益、现金激励或工厂授权。保留的 Three.js 观片器只是装饰外框，不是产品器型模型。保存作品默认私有；本机模拟公开仍需授权确认，不等于云端发布；点赞不等于入选。来源权属、正式权益、评审与生产规范待人工确认。
