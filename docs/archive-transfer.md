# 跨设备作品迁移

广场的 12 件内置范例随网页发布；个人作品、草稿和额外的本机广场发布记录保存在各浏览器的 IndexedDB。AI 邀请连接不会同步作品。

1. 在原来保存作品的电脑网页打开“我的 → 作品迁移”，导出 JSON 作品包。
2. 将文件传到手机。在同一个正式网页的“我的 → 作品迁移”中选择文件，核对新增数量，再确认导入。
3. 同编号记录保留目标设备版本，不覆盖。导入素材使用新编号，避免覆盖目标设备图片。

作品包包括草稿、作品、素材、收藏和本机广场记录，不包括 AI 密钥、访问码或连接设置。它包含个人创作内容，仅传给自己的设备。没有账号云同步；后续更新需要再次迁移，同编号的后续修改不会自动覆盖。素材总量上限 80 MB，导入文件上限 120 MB。事务提交失败不会删除或部分替换原记录。

验证：150 项单元测试通过；使用两个独立桌面浏览器手机尺寸上下文验证真实导出下载、导入、素材恢复、原有作品保留和刷新。未使用用户日常浏览器数据。
