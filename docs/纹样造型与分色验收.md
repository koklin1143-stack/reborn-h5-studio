# 手绘纹样的造型与部位分色

项目把三个问题分别验收：造型是否跟随原稿、每种墨是否落在指定部位、白墨印到不同底色上是否仍可辨认。

## 研究依据

- T2I-CompBench 将颜色绑定、形状绑定和空间关系分别评价。只统计一张图有几种颜色，会漏掉“眼睛和嘴上错了色”这类错误。[论文](https://arxiv.org/abs/2307.06350)
- ControlNet 的研究展示了边缘和线稿可以作为独立的空间条件。当前 H5 把原稿作为百炼的图像输入，并在服务器上测量部分单幅回图与原稿的边线偏差。[论文](https://openaccess.thecvf.com/content/ICCV2023/papers/Zhang_Adding_Conditional_Control_to_Text-to-Image_Diffusion_Models_ICCV_2023_paper)
- Set-of-Mark 给可见区域编号，再用视觉模型理解编号所指。项目在现有色面与小块封闭留白上建图，借鉴了这一交互方式。区域来自本地的像素分区。[作者实现](https://github.com/microsoft/SoM)
- 图像的颜色与透明度分别存储。实白颜料要保留覆盖率，纸底和原有釉缝则允许底材透出。[W3C 合成规范](https://www.w3.org/TR/compositing-1/)

## 已选定一版时

在生成结果或历史方案中选中目标，点「保留造型换色」。视觉接口只定位部件。本地用已选 PNG 的像素作底，保留外形与原有喷色的透明度；明确要求上色的内部空处可以落墨。同一部位的左右实例分别定位。

先读编号，再核对每个部位的高亮图。涉及眼睛时让模型同时区分嘴缝。位置意见不一致时至多再核对一次；仍不能确认则保留原版。定位通过后，当前本地服务缓存相同图像、相同部位集合的映射，语序和颜色值不参与缓存键。完成的配色作为独立版本写入草稿，记录来源版本、配色文字与部位。

## 首次生成时

身体与其他部位有明确配色要求时，先把每个部位作为单独的工作色版。即使角与眼都要白色，它们在制作时也有各自的编号。回图经过部位核对，再合为实际颜料。不能核实的结果显示配色尚未完成。

部分单色单幅回图会做小范围位置校正。先按主体长边等比归一，再测原笔迹到回图最近墨边的距离。仅在实际校正后的平均距离和第 90 百分位都改善时采用。缺失的部件、审美优劣与工艺可行性不由这项距离判定。

## 回归

运行 `npm test`。重点用例在 `tests/region-ink.test.cjs` 和 `tests/sketch-registration.test.cjs`。手机验收用同一造型交换部位语序，核对命中的区域与导出像素；在白底、深底检查白墨、绿墨和透明釉缝；刷新后从历史中分别重新打开原版与换色版。
