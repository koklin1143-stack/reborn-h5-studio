什么该留下，什么可以改

手绘先读原草图的题材与姿态，再用姿态简图定位耳位、重心或部件关系，配合匿名墨样一次生成平面印花。单幅面状手绘的回图会在小尺寸下检查色面与排线。遇到分叉或穿插时，先标出原画的接点与开口；有明确主次面的草图会先试放主墨与留底，再制成印花。回图还会与原画进行视觉对照。结构和线面意见留给绘图模型。可用回图会保存为候选，由创作者直接采用；主动用同一草图再试时，模型会参考上一版的意见。几笔线条难以辨认时，可依笔势生成自由线纹，题材提示选填。
照片提炼主体、两项识别特征和部件关系，略去拍摄环境。绘图模型收到设计说明，视觉识别模型读取照片。
一句话保留写明的数量、方向、动作和省略要求。抽象词优先沿用已有的意象选择。

默认单幅；文字明确提到团花或边花时依描述安排，采用后仍可在编辑器调整排布。比如同一枝带花苞的玉兰，朱红用花瓣根部的喷点连接主面，钴蓝用瓣间留白交代前后，花苞和枝干的关系仍由输入决定。

两色与三色

可以直接描述每种颜色放在哪里，也可以展开生成确认中的「指定配色」，选择两种或三种颜料。每种颜料占一个部位，未印的地方露出器身底色。记录中保留目标色值、计划部位和各版实际占比。模型漏出很小的色版时，可在已有墨迹和计划部位内补色。

工作台「调色 → 局部配色」可以换整版颜色，也可用手指重新分配颜色。对已有单色稿，主色铺底，辅色和点色由创作者涂到指定位置。笔触在源纹样上保存，随重复排布和器型预览一起更新。

进入编辑器前

三种内部画法的成图会先把纸底和内部露釉处理为透明，喷花的淡色保留为半透明油墨。用户看到同一份可上器的贴图，可直接使用或回去修改。工作台沿用这张纹样文件，并把来源、采用的画法、规则版本和模型记录在作品档案里。项目试稿只提供设计对照，工艺打样和馆方审定另行进行。

02　把输入变成设计意图

画几笔保留画者表达的题材和动作。以一只有竖耳、朝左的小狗为例，草线足以透露这个身份，模型保留鼻尖与肩的高低、长身短腿及尾巴的走向，重新画关节、脚掌和连接处。主体辨认不清时请创作者补一个词。
传照片选主角，保留姿态与一个独特细节。场景、光影、相机透视分别判断是否服务于题意。例如两颗樱桃以长短果梗和前后遮挡保持辨识度；桌布花纹和反光可舍去，再顺盘心的圆势安排两果和叶片。
词或描述具体名词变主形，动词决定朝向与呼应，颜色词指定色彩角色。「两只燕子相向」先锁定数量和动作。「团圆」这类单词先准备两个有差异的构图文字提案，如双燕相向、双鱼环游，选定一个再画。

这些是系统和设计团队用的准备工作。用户只需选参考、提供灵感；意图足够清晰即可沿用默认构图。

03　写清楚怎么画、画在哪里

  1. 先搭大形。 定一个视觉中心、一条走向和一处需保留的空地。辅助物要有作用，例如用花心承接鼻尖，用叶片方向带回视线。参考上出现的鸟、花或文字不自动加入用户主题。
  2. 重新造型。 用剪影检查主体能否辨认，再决定哪些转折用色面交界，哪些只需一笔点明。把草图与素形放在一起看，检查动作、重心与个性比例，再决定线条怎样收放。首轮筛掉色块彼此孤立、所有边都套同样细线的结果。
  3. 照母本分颜色的工作。 从同一件原物的清楚部位标出器底、主色、辅色和醒目处，记录哪一层压在哪一层。有可见晕色就标明起止位置，有清楚的套色边界就保留。工艺缺乏证据时只描述可见效果。颜色数量、描边、渐变均随母本，不设通用配方。
  4. 配合器面。 盘心或盆内底可用聚拢的主纹，关键部位留在可视范围；杯身、碗外壁或盆外壁改作横向单簇或可衔接的单元。可沿用同一个主角，按面位另排间距和停顿；杯柄、接缝、口沿避开眼睛、花心等识别点。面位未选时先保存一组可移动的主纹，后续按用户所选器型安排边饰。
  5. 保留真实的底。 底釉从器物上透出来。透明印花只保存需要印的部位；原物的亮斑、磕碰和摄影阴影留在资料照片中。若有白色颜料，作为图案的一部分保留，与镂空分别检查。

三个已有方向只改变重画的自由度。「保留经典」沿用母本的分区和色层，替换主角；「现代转译」可以简化次要笔触和重复次数；「自由融合」可以重组布局，但仍须指出借用了母本的哪项可见特征。

04　用这次截图试读规则

图中绿色色块和细线相切，右边出现齐平断口，下方花枝与上方主体各自成组。截屏足以发现构图问题，断口的成因需对照原始输出、去底图和器物预览分别判断。

假设你的题意是「一只小动物靠近一朵花」，盘心方案保留头部的转向和鼻尖到花心的空隙。把身体收成一个可辨的大形，头背的转折由主色决定，只在需要处表现耳和眼；把最醒目的花心放在鼻尖前方，剩余枝叶顺盘心下缘回转。去掉会切穿身体的花枝，给尾部留出完整空间。到杯身上则让这组关系横向展开，接缝留在疏处。这是本项目的构图提案，动物种类由创作者决定。

生图前，一句话就应能说清：依据哪件实物、采用哪个面位，保留用户哪两个特征，主形朝哪里，哪块留底，哪处设色，哪些参考元素必须舍弃。任一关键项空缺，先补卡或改构图。

05　第一轮怎样判定能用

评审时并排看用户原输入、实物母本和成品在器面上的预览。团队先回答四个问题：

  1. 遮住标题后，还认得用户的主角、数量与动作吗？
  2. 能在母本上指出至少两处对应依据吗，例如「主纹所在区域」和「浓淡分布」？仅颜色相近算一项。
  3. 在 375px 手机首屏的实际器物尺寸下，看得出主次、留白和完整轮廓吗？转到侧面时，有没有意外截断、穿柄或可见的矩形底？
  4. 对照模型原图、透明图和器物预览，浅色花瓣、眼睛、尾部是否都保留下来？按出错环节回去改构图、去底或贴图。

首批验证建议只用一件获准母本和一个面位。同一个题意分别用草图、照片和一句话输入，各生成一张，再比较。主体换掉、关键部位断裂或依据说不清的候选退回，记录原因。这个评审只判断数字设计；实物制作另需打样。
